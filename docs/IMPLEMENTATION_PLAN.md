# Реализация

Объём ограничен исходным заданием: публичные книги Binance/Aster, независимое восстановление, консистентное хранение и игрушечный сигнал без исполнения.

Выполнено:

1. Точный fixed-point парсинг, `Price`/`Qty`, параметры и лимиты.
2. Декодирование metadata/snapshot/diff обеих площадок.
3. Книга на массивах по шагу цены, битовые карты, откат затронутых ячеек и контроль покрытия.
4. Публикация актуальных лучших 20 уровней каждой стороны роботу через triple buffer; статические счётчики разрывов гарантируют Offline/Hold перед восстановлением.
5. Робот: Long/Short относительно Aster, Hold при недоступных/несвежих данных.
6. Независимые адаптеры: snapshot + diff, reconnect, backoff, watchdog.
7. Запуск потоков, supervision и SIGINT/SIGTERM.
8. Короткие цветные логи и обоснование решения числами обеих книг.
9. Проверки ядра, восстановления и публичных соединений.

После сверки с заданием удалены неиспользуемая арифметика, тестовые методы в рабочем API, каналы статистики и повторяющиеся транспортные тесты. Сохраняются только проверки поведения и инвариантов.

Синтетический замер готовый JSON → смена bias выполнен в рабочей схеме потоков; сеть/TLS в него не входят. Результаты оптимизаций и ограничения — в [проверках](VALIDATION.md).
